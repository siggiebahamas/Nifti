Other pages with tabs: how to make each simpler

These are every page that still has a tab row. One rule decides it:

Keep tabs only when they are truly different jobs. Otherwise use one page with filter chips or jump links.
  • Filter chips narrow one list, so nothing is hidden behind a click you might forget.
  • Jump links scroll down one long page and still show everything.
  • Small "settings" tabs become a gear button in the corner.
